PACOTE FINAL: PC + ANDROID + IOS

1. ABRIR NO COMPUTADOR
- Extraia o arquivo ZIP.
- Abra a pasta e dê dois cliques em index.html.
- O site abre no navegador.

2. PUBLICAR NA INTERNET
- Envie todos os arquivos desta pasta para a hospedagem.
- O arquivo principal deve permanecer como index.html.
- Não renomeie logo.jpg, a pasta icons, manifest.webmanifest ou sw.js.
- Para instalar como aplicativo (PWA), a publicação deve usar HTTPS (ou localhost para testes).

3. ANDROID
- Abra o site no Chrome.
- Use o menu do navegador e escolha “Adicionar à tela inicial” ou “Instalar aplicativo”, quando disponível.

4. IPHONE / IPAD
- Abra o site no Safari.
- Toque em Compartilhar > Adicionar à Tela de Início.

5. WHATSAPP
- O site está configurado com um número de exemplo: 55 33 99840-6857.
- Antes de publicar, substitua 5533998406857 no index.html pelo seu número real, com código do país e DDD, somente números.

6. INSTAGRAM
- O espaço para Instagram pode ser incluído no menu/rodapé quando o usuário informar o @ oficial.

7. PERSONALIZAÇÃO
- Textos, serviços e cores ficam no index.html.
- Para trocar o logo, substitua logo.jpg por outro arquivo mantendo o mesmo nome e formato.

ARQUIVOS PRINCIPAIS
- index.html
- logo.jpg
- manifest.webmanifest
- sw.js
- favicon.png
- icons/icon-180.png
- icons/icon-192.png
- icons/icon-512.png
